# Core dependencies of the Retrieval & Memory Lab.
#
# Three kinds of line, on purpose:
#   ==  exact pins for what this lab adds and Colab doesn't ship -- a different version of
#       these changes behaviour you'd otherwise attribute to your own design;
#   ==  pins MATCHED TO COLAB for pure-Python packages Colab already ships, so installing
#       is a no-op there and your local venv behaves like the runtime you'll be graded on;
#   >=  ranges for compiled packages Colab ships (torch, numpy): an exact pin that misses
#       Colab's build reinstalls ~2.5 GB of CUDA wheels or forces a runtime restart.
#
# Per-corpus parsers are in requirements-corpora.txt; optional frameworks (LangChain,
# LangGraph, LlamaIndex, RAGAS, Chroma, FAISS) in requirements-extras.txt. Your group's
# own additions go in requirements-group.txt, which the Colab bootstrap installs if present.
#
# The LLM runs in Ollama (a separate server, not a pip package); llm.py talks to it over
# HTTP with `requests`.
